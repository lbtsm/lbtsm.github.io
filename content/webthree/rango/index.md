## 导读

这篇是跨链聚合器系列的第二篇。上一篇[路由协议-lifi](../lifi/)把"跨链聚合器"这个物种是什么、内部怎么运作讲透了;这一篇讲它最大的同行 **Rango**——重点不在重复概念,而在回答一个问题:**同一个赛道,Rango 和 LI.FI 到底差在哪,差异是怎么长出来的。**

一句话预告:LI.FI 选择在 EVM 世界里往**深**做(一个 Diamond 合约、一笔原子交易搞定一切),Rango 选择往**广**做——把 Bitcoin、Cosmos、Solana 这些"没法一笔交易搞定"的链全吃下来,代价是执行模式变成了多步多签。**这个取舍是理解 Rango 全部设计的钥匙。**

这篇的结构:一到三节是普及部分——Rango 是什么、和 LI.FI 的分岔点在哪、两套 API 怎么选;四到六节往深处挖——多步编排在分布式系统意义上到底是什么、比特币这种没有合约的链靠什么被信任、以及聚合器的经济模型(一笔单子的钱到底流进了谁的口袋)。赶时间看前半就够用,想知道所以然再看后半。

## 一、Rango 是什么

链多了以后,钱是碎的:BTC 在比特币链上,ATOM 在 Cosmos 里,USDC 散在七八条 EVM 链上。想把 A 链的某个币变成 B 链的另一个币,你得自己挑桥、两头换币、盯着每一步别卡住——这套麻烦事上一篇讲过了,不再展开。

Rango 就是干这个的**跨链聚合器**:2021 年 8 月上线,你告诉它"从哪条链的什么币,到哪条链的什么币",它负责比价、选路、生成交易、跟踪进度。它自己**不建桥、不开池子**,只是站在几十座桥和一堆 DEX 的头顶上做导航——你可以把它理解成跨链世界的高德地图:路(桥)和车(DEX)都是别人的,它只负责告诉你怎么走最省,并把整个行程串起来。

规模感受一下(截至官方文档):

- **约 87 条链**:39 条 EVM 链(Ethereum、Arbitrum、Base、BSC……)+ **38 条 Cosmos 系链**(Osmosis、Injective、dYdX、Noble……)+ 10 条"其他"——**Bitcoin、Bitcoin Cash、Litecoin、Doge、Dash 这五个 UTXO 兄弟**,加上 Solana、Tron、Ton、StarkNet、Sui。
- **约 27 个 DEX/聚合器**:EVM 上直接套用 1inch、Paraswap、OpenOcean 这些现成聚合器,Solana 用 Jupiter,Cosmos 全系走 Osmosis。
- **约 21 座桥**:Across、Stargate、Hop、cBridge、Wormhole、各链官方桥,非 EVM 侧靠 IBC、Axelar、THORChain。

注意 DEX 那条的做法:Rango 在 EVM 上**连"同链聚合"都不自己做**,直接调 1inch 们。它把自己的定位钉得很死——只做"跨链拼路"这一层,同链比价是别人已经卷完的战场,拿来用就好。

## 二、和 LI.FI 的分岔点:广度 vs 深度

两家解决的是同一个问题,分岔发生在"支持哪些链"这个看似简单的选择上。

**LI.FI 的世界基本是 EVM 的世界。** EVM 链有智能合约,所以 LI.FI 能玩出上一篇讲的那套优雅架构:一个 `LiFiDiamond` 合约当唯一入口,把"源链 swap → 上桥 → 目标链 swap"编成**一笔原子交易**,失败整体回滚,用户签一次名就完事。

**Rango 的野心是"任何链到任何链",于是撞上了硬约束。** Bitcoin 上没有智能合约——你没法在比特币链上部署一个 Diamond,更没法把"换币 + 跨桥"打包成一笔原子交易;比特币的"发交易"就是把 BTC 转给某个地址、最多附一行备注(比如打给 THORChain 的金库地址,备注里写明目标链和收款人)。Cosmos 那 38 条链各有各的交易格式,Solana、Ton、StarkNet 又是各自完全不同的虚拟机。

**链上没法原子组合,就只能链下编排。** 这就是 Rango 架构的成因:一条跨链路线被拆成若干**步**(step),每一步是某条链上的一笔交易,**用户每步至少签一次名**,Rango 的服务端负责排序、生成每步的交易、盯着上一步到账再发下一步。优雅换成了泥泞,但泥泞换来了别人到不了的地方——"把 BTC 换成 Osmosis 上的 ATOM"这种单子,纯 EVM 聚合器根本接不了。

一个具体例子感受多步的样子:

```
BTC ──① 打给 THORChain 金库(BTC 链上一笔转账,签名 1)──▶ 换出 ETH
     ──② ETH 走桥去 Cosmos 生态入口(EVM 交易,签名 2)──▶
     ──③ IBC 转到 Osmosis 换成 ATOM(Cosmos 交易,签名 3)──▶ 到账
```

三条链、三种签名体系、三笔交易,中间任何一步都可能等几分钟。Rango 的价值就是把这串杂技编排好、跟踪好,你只管按提示依次签名。

## 三、两套 API:Basic 和 Main

上面的"多步"听着吓人,但其实**大部分单子用不着**。Rango 把产品切成了两套 API,对应两种情况:

| | **Basic API**(单步) | **Main API**(多步) |
|---|---|---|
| 用户签几次 | **1 次** | 每步至少 1 次 |
| 路线覆盖 | 约 85% 的路线 | 全部路线 |
| 价格 | 约 95% 的情况已是最优 | 所有路径都拿最优价 |
| 中间链 gas | 不需要 | **中间链上得自备 gas 币** |
| 典型场景 | EVM ↔ EVM、常规跨链 | BTC/Cosmos 参与的长路线 |
| SDK | `rango-sdk-basic` | `rango-sdk` |

**Basic API** 走的路子和 LI.FI 一样:在 EVM 链上,"源链 swap + 跨桥 + 目标链 swap"整套动作打包进**一笔签名**。官方自己都说,绝大多数集成方用它就够了。

**Main API** 就是 Rango 官网 dApp 用的那套完整引擎,流程大致是:拉元数据(有哪些链、币、swapper)→ 要**最优路线** → 用户确认后**逐步生成交易**、逐步签名、轮询每步状态,签名或广播失败还有专门的上报接口。它换来的是全覆盖和全路径最优价,代价除了多次签名,还有一个容易被忽略的坑:**路线经过的中间链上,你得有那条链的 gas 币**——路线借道 Osmosis,你钱包里就得有一点 OSMO 付手续费。

接入姿势和 LI.FI 一样分三层:**Widget**(一段代码嵌一个完整换币 UI)、**SDK/API**(数据和执行自己拼 UI)、以及给钱包/dApp 用的联盟分成体系。选择逻辑也一样:要快用 Widget,要灵活用 SDK。

## 四、谁在替比特币执行逻辑:THORChain 的信任模型

在上述的例子里,第一步是"把 BTC 打给 THORChain 的金库地址"。这里藏着一个值得单独拆开的问题:比特币上没有合约,那笔 BTC 打过去之后,**凭什么保证对面真的把 ETH 换给你**?收款的只是一个普通的比特币地址,如果它背后是一个人,人家收了钱直接跑路,链上没有任何东西拦得住。

THORChain 的答案分两层:

- **钥匙没有单点**。金库地址的私钥不归任何人,由上百个节点用 **TSS(门限签名)**共同生成、分片保管——从金库转出一笔钱,需要超过阈值数量的节点协作签名,任何单个节点(包括项目方自己)手里都凑不出完整私钥。金库像一个要几十把钥匙同时插进锁孔才能打开的保险柜。
- **作恶不划算**。每个节点入场要抵押大额 RUNE 债券,协议的经济规则要求全网债券的价值高于金库托管的资产——节点们就算串谋把金库偷空,被罚没的债券也比偷到的钱多。防的不是"能不能作恶",是"作恶值不值"。

所以那行备注(memo)才敢被当成"合约"用:它本身只是一句意图声明,真正的执行,靠的是一群被抵押品捆住手脚的节点。这套"TSS 共管金库 + 超额债券"是在没有智能合约的链上做资产托管的通用范式;而 Cosmos 侧的 IBC 是另一套思路(两条链互相跑轻客户端验证对方的区块头,根本不需要托管方)。同样是 Rango 路线里的一步,背后的信任结构可以完全不同。

对 Rango 这一层,结论要说透:**聚合器自己几乎不背信任,它把信任外包给了路线上的每一环**。你的 BTC 安不安全,取决于 THORChain 的债券够不够厚;你的 USDC 过不过得去,取决于那座桥的验证机制;Rango 背的只有"报价诚实、编排不出错、出事及时下架路线"。这是典型的轻资产生意——不锁仓、不养金库、不发债券,所以它敢铺 87 条链;也正因为如此,下面风险清单里"看清路线里的桥是谁",永远是你自己的作业,聚合器替不了。

## 五、经济模型:一笔 1000 美元的单子,钱是怎么分的

导航不收过路费,那 Rango 吃什么?这一节把钱的流向拆开讲。先给一个总框架:一笔跨链单的成本分三层——**执行层拿大头,分发层拿中头,聚合层(也就是 Rango 自己)只拿零头**。下面按这个顺序展开。

### 跟着 1000 美元走一遍

假设你在某个钱包 App 里把价值 1000 美元的 ETH 换成另一条链上的 USDC,而这个钱包嵌的正是 Rango 的 Widget。这 1000 美元在路上被这么切:

```
1000 美元进场
 ├── gas 费(两条链各一笔)——————→ 几美元,付给矿工/验证者,和 Rango 无关
 ├── DEX 手续费(约 0.3%)—————→ 约 3 美元,付给 DEX 池子里的流动性提供者(LP)
 ├── 桥的费用(约 0.05%~0.3%)——→ 约 1~3 美元,付给桥的 LP 或桥协议
 ├── 钱包加收的 affiliate 费(假设 0.5%)→ 5 美元,归嵌 Widget 的这个钱包
 ├── Rango 平台费(0.15%)————→ 1.5 美元,归 Rango
 └── 滑点(不固定)————————→ 不是谁的收入,是你的单子把池子价格"推走"的损耗
```

看清比例:这笔单子的显性成本十几美元,**归 Rango 的只有 1.5 美元**——桥和 DEX 的 LP 拿得比它多,嵌它的那个钱包拿得也比它多。三层分账正好对应三种角色:

- **执行层**(桥、DEX 背后的 LP,矿工):真金白银把资产锁在池子和金库里、承担被黑被清算的风险,所以拿大头。和上一节信任模型对起来看,这是同一件事的两面——**谁背信任,谁收租**;
- **分发层**(钱包、dApp):带来用户,拿中头;
- **聚合层**(Rango):只出算法和编排,不锁一分钱资产,拿零头。

### 两个收入口:平台费和 affiliate

- **平台费**:默认在报价上叠约 **0.15%**。有个细节能看出行业位次:Rango 把这笔费用在报价里**单独列示**,而 LI.FI、Socket 是揉进报价里的——后发者拿透明度当卖点。
- **联盟分成(affiliate)**:接了 Widget/SDK 的钱包和 dApp,可以在 Rango 的费率之上再加自己的一层,从用户的输入金额里扣,即时或按月结算。这是聚合器的分发引擎——让别人有动力把你嵌进他们的产品里。

### Fees 不等于 Revenue:数据怎么读

去 DefiLlama 之类的数据站看聚合器,有两个必须分开的口径:**Fees(总费用)**是流经这个协议的全部服务费——Rango 的平台费加上所有集成方的 affiliate 费;**Revenue(协议收入)**才是协议自己揣进兜里的部分。Rango 近 30 天的数字:总费用约 **102 万美元**,自留只有约 **2 万美元**;年化总费用约 940 万美元,自留约 17 万。换句话说,**流经它的每 100 块服务费,它自己留 2 块,98 块让给了带来流量的集成方**。

### 为什么把 98% 让出去

因为聚合器这个位置,几乎没有锁住用户的手段:它不托管资产(用户抬腿就走)、路线算法构不成专利(报价好不好,用户逐笔就能比出来)、桥和 DEX 是公共设施(对手也接得上)。唯一能构筑的壁垒是**网络效应**——被嵌进的钱包和 dApp 越多,订单流越大;订单流越大,越有底气跟桥和 DEX 谈费率、要集成优先级,报价就越有竞争力;报价有竞争力,又吸引更多集成方。affiliate 分成就是给这个飞轮上的油:**把每一个集成方都变成自己的销售**。

这个剧本你其实见过:**Visa**。你刷卡付的手续费,大头分给发卡银行(渠道),Visa 网络自己每笔只抽极薄一层,靠"所有商户都收、所有银行都接"的网络效应,把薄利乘上天量的交易笔数。聚合器赌的是同一条路:现在让利换规模,等"全行业的跨链单都从我这儿过"成真,零头乘以天量也是大生意。风险也是同一个:飞轮转起来之前,薄利就只是薄利——年自留 17 万美元,养不起一个几十人的团队,烧的还是融资的钱。

和美股券商 Robinhood 的订单流模式(把用户订单卖给做市商换收入)放在一起看很有意思:一个卖用户、一个买渠道,方向相反,却是同一条规律的两面——**入口值钱,执行不值钱**。

### 发币:薄利生意的第二曲线

也正因为自留这么薄、用户又没有锁定,聚合器们都在找第二曲线:LI.FI 押 intents,Rango 的路线图里则挂着 **RANGO 代币**(以太坊上已经能查到一个 10 亿总量的同名代币合约)。代币能给这门生意补什么?行业通行的剧本是:持币给手续费折扣(锁用户)、给集成方分成加成(锁渠道)、按历史交易量空投(把过去的让利变成股东式的绑定)、治理投票决定路线上架和费率(把规则制定权分出去换忠诚度)。说白了,**发币是想把飞轮上的每个参与者都变成利益相关方**,去补"协议层留不住人"这个先天缺陷。不过官方发行细节至今未落地,这种"预期发币"阶段恰恰是假币最泛滥的时候,真要参与,合约地址务必从官方渠道核对。

## 六、聚合器不会替你消灭的风险

Rango(以及所有聚合器)帮你**选**桥,但不替你**扛**桥:

- **桥暴雷,聚合器只能事后拉黑。** Rango 文档里就躺着现成的案例:Multichain 被黑之后,Fantom 链整个被 Rango 暂停;Harmony 被黑,同样下架。聚合器的应对是"出事后把路线关掉",但**出事那一刻走在桥上的资金,聚合器救不了**。你走的每条路线里桥是谁,值得看一眼。
- **多步路线有"中间态"。** 单笔原子交易要么全成要么全退;多步路线可能停在半路——BTC 已经换成了 ETH,下一步桥堵了,你的资产就以中间币的形态停在中间链上。Rango 会跟踪并引导你继续或者取回,但"卡在半路"这个状态本身,是多步模式的固有产物,心理上要有预期。
- **报价有时效。** 跨链路线动辄几分钟,行情动了,实际到手可能贴着滑点下限走。长路线里每一步都有自己的滑点,叠起来比单步的偏差更大。
- **非托管 ≠ 不用信任何东西。** Rango 不碰你的私钥、不托管资产,这是真的;但你签的每笔交易的 calldata 是它的 API 生成的,"签之前看一眼要交互的合约、金额、授权额度"这个习惯,在哪个聚合器上都不能省。

## 七、Rango vs LI.FI:一张表收尾

| | **Rango** | **LI.FI** |
|---|---|---|
| 路线 | **广**:87 条链,吃下 BTC/Cosmos/Solana/Ton | **深**:深耕 EVM,架构做到极致 |
| 执行模式 | Basic 单签 + Main 多步多签 | 一笔原子交易(Diamond 合约) |
| 非 EVM 覆盖 | **核心卖点**(UTXO 五兄弟、Cosmos 38 链) | 有限 |
| 同链聚合 | 直接调 1inch/Paraswap 们 | 有自己的链上路由,也调外部聚合器 |
| 失败形态 | 多步路线可能停在中间态 | 原子回滚(单笔内) |
| 意图/intent | 有 gasless 和 intents 方向的探索 | LI.FI Intents 已是独立产品线(OIF 官方实现) |
| 适合谁 | 路线里有 BTC、Cosmos、多虚拟机需求 | 纯 EVM 世界里要最顺滑的单签体验 |

一句话选型:**单子不出 EVM 世界,两家都行,LI.FI 的单笔原子体验更顺;路线里出现了 Bitcoin、Cosmos、Ton 这些字眼,基本就是 Rango 的主场。** 而对写代码的人来说,这两家放在一起看最有营养的地方在于:同一个问题,因为"支持哪些链"一个选择,长出了"链上原子组合"和"链下多步编排"两套完全不同的架构——约束塑造架构,这比任何一家的文档都更值得记住。
